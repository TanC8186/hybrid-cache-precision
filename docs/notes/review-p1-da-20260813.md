## Scoring Plan

### D1: methodology_rigor
dimension_id: D1
what_to_look_for:
- 测量口径漏洞：latency/throughput 是否只报 mean/median 而无尾延迟（P99）；是否声明 warmup、冷/热启动、并发模式；关键数字是否来自多次运行并报 std/CI，还是单次运行；seed 是否受控且结论对 seed 稳定；内存/带宽数字是否为实测（日志/计数器）而非理论推算或默认值兜底。
- 公平性攻击面：baseline（uniform 量化、per-layer 独立量化、FP16 基线等）是否获得与作者方法同等的调优工作量（equal tuning budget）；搜索空间粒度是否对作者方法先验有利；baseline 配置是否为其最优形态而非随手默认。
- 配置真实性核查：精度/budget 配置是否被验证真正生效——启动日志 override、实际 dtype、实际内存占用与预算是否三方一致；是否存在静默 fallback、kernel 未生效、缓存残留（跨运行 KV cache 复用）等假象风险。
- 统计与报告完整性：关键对照有无统计支撑；消融是否覆盖联合分配的两侧（去 joint 留 KV-only 优化、去 joint 留 state-only 优化）；敏感性分析是否检验 budget 约束的紧度与收益的鲁棒区间；错误条是否只出现在有利图里。
- 可复现性：代码/配置/环境的可获得性；MLSys artifact evaluation 预期的满足程度；他人能否仅凭论文材料重建核心数字。
what_triggers_block:
- 主结果经不起测量质疑且无法从论文材料排除：headline 收益来自无方差单次运行、未 warmup、或对 baseline 明显不公平的调优预算，且无任何补充证据可辩护；
- 有证据表明关键配置未真正生效（静默 fallback / no-op 实锤），而 headline 结论依赖该配置；
- 论文内部数字自相矛盾（正文 vs 表格 vs 图对不上），或声称的可复现材料完全缺失，使核心数字无法验证。
what_triggers_warn:
- 证据方向性支持结论但无统计支撑（单模型、单硬件、无多次运行、无方差报告）；
- baseline 调优投入可疑但无法确证不公平；
- 消融/敏感性分析不完整（如缺一侧隔离），但现有证据仍支持主结论方向；
- 关键实现细节缺失但可通过补充材料修复，尚不足以阻断他人重建。

### D2: domain_accuracy
dimension_id: D2
what_to_look_for:
- 术语与概念准确性：linear attention / SSM / recurrent state / hybrid 等术语是否混用、错用或偷换；"joint precision budgeting" 是否与领域内 mixed-precision assignment、per-tensor/per-layer quantization 文献正确区分而非换名。
- Prior work 表述忠实度：KV cache 量化（KVQuant、KIVI、Atom、ZipCache 等）、SSM/state 量化、hybrid 模型 serving 的既有结论是否被准确转述；有无把 baseline/prior work 写得比实际更弱（strawman）；有无直接先例（尤其 hybrid 模型联合量化或 joint budget 的先例）被遗漏——遗漏即构成 novelty 攻击点。
- 事实性声明的可查证性：KV 与 recurrent state 的精度敏感度差异声称是否与领域已知证据一致或至少不冲突；硬件行为（带宽/计算特性）陈述是否可信；论文中的数字与领域可查证数据是否矛盾。
what_triggers_block:
- 论文的核心领域性前提（如"recurrent state 与 KV 的精度敏感度存在系统性差异，因此值得联合分配预算"）与领域公认证据直接冲突，或建立在对其 prior work 的事实性错误转述之上；
- 存在被遗漏或歪曲的直接先例，使 novelty 声称在领域层面不成立（更强的替代叙事是"这已被做过"）；
- 术语/概念错误严重到使技术主张无法被正确评估（如混淆两种机制而结论恰好依赖其区分）。
what_triggers_warn:
- 相关工作覆盖不全、个别转述过度简化或引用有选择倾向，但主论点的事实基础仍然成立；
- 术语使用不严谨但上下文可解，不误导核心判断；
- 对 prior work 的对比方式有利于己方叙事，但结论仍有独立证据支撑。

### D3: argumentative_coherence
dimension_id: D3
what_to_look_for:
- 核心逻辑链完整性：从前提（两组件精度敏感度不同 / 共享资源约束）到结论（联合分配优于独立分配）的每一步是否有对应实验证据；是否偷换比较对象——证明"joint 优于 uniform"却宣称"joint 优于 per-component 各自最优"。
- 循环论证风险：方法本身若是搜索/求解器，则"搜索出的配置效果好"不是方法有效性的独立证据——检查收益是否只是调优工作量从 baseline 转移到作者方法。
- 收益归因：joint 的收益是否可能完全来自单一组件（仅 recurrent state 改进或仅 KV 改进）；关键 ablation 是否隔离了"joint 机制本身"这一变量。
- 一致性审查：abstract 的宣称强度 vs 正文证据强度；结论范围是否超出实验覆盖（单模型→全家族、单负载→全工况、特定硬件→一般性）；负面结果/反例是否被省略而非讨论。
what_triggers_block:
- 主结论在逻辑上不能从所呈证据推出（数据只支持"joint ≥ uniform"却宣称"joint ≥ 独立最优"，且无对应实验）；
- 核心收益被 ablation 证明来自非核心机制（去掉 joint 分配、仅保留单一组件改动后收益不变），即方法与结论脱节；
- 论文自身数据反驳核心论点（存在独立分配优于联合分配的配置/工况），而论文回避该证据且未限定结论边界。
what_triggers_warn:
- 论证存在跳跃或过度宣称，但证据支持主要方向；
- 归因分析不完整（缺少关键隔离实验），但机制解释仍属合理而非循环；
- 选择性呈现存在（回避部分不利工况），但未根本动摇结论且已做部分限定。

### D4: cross_disciplinary_relevance
dimension_id: D4
what_to_look_for:
- 可访问性：SSM/linear-attention 的机制性前提（为何 state 与 KV 的精度敏感度不同、为何两者可共享预算）是否对非该子领域的 MLSys 读者自足解释，还是依赖术语黑箱与"众所周知"。
- 跨领域主张的支撑度：面向整个 hybrid linear-attention 类别、或与 attention-only 架构对比的结论，是否有跨模型/跨架构实验支撑，还是单模型外推；是否给出了主张成立的条件边界。
- 度量可操作性：precision budget 的度量单位（bit×token？内存预算？误差预算？）是否对相邻领域读者可理解、可操作、可与既有系统指标换算。
what_triggers_block:
- 论文的核心贡献依赖未解释且非自明的机制性声称，使 MLSys 主体读者（非 SSM 子领域专家）无法评估其有效性——论文只对极小同行圈成立（本维度为 high-priority，单独 block 即按 F3 触发 major_revision）；
- 跨领域/跨架构结论完全无对应证据支撑，属纯外推且被作为主贡献呈现。
what_triggers_warn:
- 术语解释不足、动机对相邻领域读者不友好，但核心机制经努力可理解；
- 泛化声明过强但已被部分限定（如注明"在本模型/本硬件上观察"），主要结论未越界。

### D5: writing_and_structure
dimension_id: D5
what_to_look_for:
- 图表自足性：evaluation 表格能否脱离正文独立读懂（baseline 名称、硬件、单位、误差口径、对比方向）；系统概览图与正文方法描述是否一致；图/表数字与正文引用是否吻合。
- 结构完整性：5086 词体量下是否以牺牲关键设定说明为代价塞入叙事；关键实验设定是否藏在脚注/附录而正文直接引用；消融与主结果的组织是否清晰。
- 规范符合度：MLSys 排版、引用、图表规范；术语首次出现的定义；数字的有效数字与单位一致性。
what_triggers_block:
- 图/表与正文出现实质性矛盾，且该矛盾直接动摇主数字的可信度（此情形我会将其升级为 D1 或 D3 的 block 证据，而非仅停留于本维度）。
what_triggers_warn:
- 图表可读性差、关键设定需反复回溯附录、结构失衡或信息密度不均——但不影响对结论的判断，可经修改修复。
