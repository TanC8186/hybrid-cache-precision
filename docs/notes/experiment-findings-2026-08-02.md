# 混合模型 KV 压缩实验综合记录（2026-08-02）

> Qwen3.5-2B（18 Gated DeltaNet + 6 GQA 注意力层，索引 [3,7,11,15,19,23]）
> 全部结果经对抗式代码审查 + 3-seed 统计验证。

## 一、核心结论（三支柱）

### 支柱 1：4-bit 是甜点位（近无损）
| 位宽 | 2048 ctx PPL (3-seed) | 4096 ctx PPL | 说明 |
|---|---|---|---|
| 8-bit | 11.48±1.57 | 11.49 | = FP16（无损） |
| 4-bit | 11.67±1.61 | 11.77 | 近无损（+0.2） |
| 3-bit | 13.53±1.87 | — | +2.1，明显退化 |
| 2-bit | 19.00±3.19 | 18.80 | +7.5，崩塌 |
| FP16 | 11.48±1.57 | 11.48 | baseline |

### 支柱 2：字节预算排序——驱逐 > sub-4bit 降 bit
等字节预算下"高精度+驱逐"始终优于"低精度+全保留"：
| 上下文 | 等字节对比 | 结果 |
|---|---|---|
| 2048 | 4bit keep1024 (3.19MB, 11.85) vs 2bit 全保留 (3.37MB, 19.00) | 4bit+驱逐完胜 |
| 2048 | 4bit keep1536 (4.79MB, 11.71) vs 3bit 全保留 (4.85MB, 13.53) | 4bit+驱逐胜 |
| 4096 | 4bit keep2048 (6.39MB, 11.92) vs 2bit 全保留 (6.74MB, 18.80) | 4bit+驱逐完胜 |

**结论：省 KV 字节应驱逐 token，而非压到 3/2-bit。**

### 支柱 3：逐层敏感度异构
| 层 | 2-bit 时 PPL | 敏感度 |
|---|---|---|
| 3 | 13.20 | -5.9%（不敏感，可白送 2-bit） |
| 7/11/15/19 | 13.98-14.24 | +5~8% |
| 23 | 15.76 | +28.7%（最敏感） |

**结论：末层注意力层（23）对 KV 量化最敏感，需保护；早层可激进压缩。**
异构位宽验证：只保 layer23 的 aggressive 分配在 2-bit 级字节下 PPL 比均匀 2-bit 好 12%。

## 二、方法定位（论文贡献）

1. **混合架构 KV 压缩的首次系统研究**（文献尽职调查确认无人做过）
2. **字节预算排序结论**：驱逐 > sub-4bit 降 bit（首次在混合模型验证）
3. **逐层异构预算**：基于敏感度分配（末层保 4-bit、早层 2-bit/驱逐）

## 四、已披露口径（论文需写明）
- 字节 = 打包后理论字节（int8 存储实际 8x）
- 驱逐分数基于压缩模型 + 滞后一拍（H2O 在线近似）
- 语料拼接切固定长度（为触发驱逐预算）
- 5 序列/seed 的 std 较大（Wikitext 异质）；最终 headline 需更多序列
