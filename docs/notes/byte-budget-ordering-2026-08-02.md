## 实验设置
- 模型：Qwen/Qwen3.5-2B（18 Gated DeltaNet + 6 GQA 注意力层，索引 [3,7,11,15,19,23]）
- 评测：Wikitext-2-raw-v1 test，拼接后切 5 条 × 2048-token 序列，chunk=128，逐 token 量化
- 位宽 {2,3,4,8} × 驱逐保留 {2048(全), 1536, 1024, 512}，16 配置 + FP16 baseline
- 指标：PPL（greedy，确定性）+ 6 层 GQA KV 量化字节（打包后理论字节，含 scale 开销）
- 审查修正：驱逐 window=256≥chunk、全部 token 计分、fp32 loss

## 结论

### 1. 混合模型上 4-bit 近无损（印证 llama.cpp #21385）
8-bit 无损、4-bit +1.7% 近无损、3-bit +16%、2-bit +55%。张力区在 sub-4bit。

### 2. 等字节预算下"高精度+驱逐"始终优于/持平"低精度+全保留"
| 字节预算 | 胜出 | 落败 |
|---|---|---|
| ~2.5MB | 3bit keep1024 (16.23) | 2bit keep1536 (21.12) |
| ~3.2MB | 4bit keep1024 (14.10) | 8bit keep512 (15.06) |
| ~4.8MB | 4bit keep1536 (13.89) | 3bit 全保留 (15.87) |
| ~6.4MB | 4bit 全保留 (13.86) | 8bit keep1024 (13.88) |

**核心排序结论：混合模型 sub-4bit 区驱逐 > 降 bit。**
4-bit 是甜点位（近无损 + 3.9x）；省字节应驱逐 token 而非压到 2/3-bit。

## 与文献的关系
- 支持 llama.cpp #21385（q4 无损）、TurboQuant（2-bit value 瓶颈）、SCBench（量化保 token 优于驱逐）
- **首次在混合架构（Gated DeltaNet + 6 GQA）上验证该排序**——文献尽职调查确认无人在混合模型上做过
- QPruningKV/RDKV/ARKV 在标准 Transformer 上做联合预算，未触及混合架构三特性

## 已披露的口径（论文需写明）
- 驱逐分数基于压缩模型测得 + 滞后一拍（H2O 在线近似）
- 字节 = 打包后理论字节（int8 存储实际 8x，vLLM kernel 阶段才真实打包）
- 语料拼接切 2048（为触发驱逐预算）
